# Pyae Zaw | Portfolio

Personal portfolio for **Pyae Zaw**, showcasing work in digital marketing, technical writing, creative production, and web development.

**Live portfolio:** [pyaezaw03a.github.io/PyaeZawPortfolio](https://pyaezaw03a.github.io/PyaeZawPortfolio/)

## About

The site brings together selected roles, brand experience, services, skills, projects, and qualifications in one responsive portfolio. It includes previews of the Level 4 and Level 5 Computing Diplomas, with links to their full diploma and transcript documents, and a Duolingo English Test certificate summary.

## Sections

- **About** - background, location, and work preferences
- **Services** — digital marketing, market analysis, and creative work
- **Experience** — selected roles and associated brands
- **Education & Certifications** — computing diplomas and English proficiency
- **Skills** — marketing, creative, AI, and technical tools
- **Contact** — email and project inquiry form

Selected web work includes the [Circuit Media website](https://circuitmedia.site.je/).

## Built With

- [Next.js](https://nextjs.org/) and React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React icons

## Run Locally

Requirements: Node.js and npm.

```bash
git clone https://github.com/pyaezaw03a/PyaeZawPortfolio.git
cd PyaeZawPortfolio
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To create a production build:

```bash
npm run build
```

To build with the GitHub Pages path settings:

```bash
GITHUB_PAGES=true npm run build
```

## Project Layout

- `app/` — routes, page layout, and global styles
- `components/portfolio/` — reusable portfolio sections and cards
- `data/portfolio.ts` — profile copy, experience, skills, and credentials
- `public/assets/` — profile, brand, and certificate images and documents
- `.github/workflows/deploy.yml` — GitHub Pages build and deployment

Most portfolio content can be updated in `data/portfolio.ts`.

## Deployment

The GitHub Actions workflow builds and publishes the static site when changes are pushed to `main`.
